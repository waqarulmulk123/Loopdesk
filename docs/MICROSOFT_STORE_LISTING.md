# Microsoft Store listing

Use this description verbatim at the beginning of the Store listing until the
self-contained package has been uploaded and certified:

> Requires the Microsoft .NET Desktop Runtime, which is installed by Loopdesk
> when needed. An internet connection is required to browse and download cloud
> wallpapers.

Loopdesk brings animated video wallpapers to Windows 10 and Windows 11. Browse
the online catalog, download the wallpapers you choose, and apply them with the
native Windows renderer.

Loopdesk does not scan or upload files from your drives. Downloaded wallpaper
data is stored in the app's protected local vault and can be removed from the
Library.
